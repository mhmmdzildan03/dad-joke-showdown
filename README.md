A tiny Python program that writes one dad joke to /output/entry.txt: "I renamed my Wi-Fi Martin Router King, because I have a stream." One word of the most famous sentence a father can quote is swapped — dream becomes stream — so the pun lands the instant it is heard and the punchline is the last word.

## Run it

```sh
python3 main.py
```
